## 📌 Featured Projects

### 🩸 Enhancing Glycemic Control in Diabetes Using Artificial Intelligence and Machine Learning

A machine learning project focused on predicting blood sugar fluctuations using patient data to support early intervention and improved treatment decisions.

*   **Technologies:** Python, Machine Learning, Pandas, Scikit-learn, Jupyter Notebook
*   **Key Highlights:**
    *   Developed a predictive model using AI and machine learning algorithms.
    *   Analyzed patient data to forecast blood sugar fluctuations.
    *   Applied data processing and machine learning techniques using Python.
    *   Designed the system to support early intervention and data-driven treatment decisions.

### 🩸🏨 Blood Donation Portal Using Full Stack Development

A web-based platform designed to connect blood donors with recipients and simplify the process of finding potential donors.

*   **Technologies:** HTML, CSS, JavaScript, Node.js, Express.js, MongoDB
*   **Key Features:**
    *   Donor registration and user management.
    *   Blood-group based donor search.
    *   Nearby donor discovery.
    *   Responsive and interactive user interface.

### 🔎 Lost and Found Management System

A web application designed to streamline lost-and-found item reporting and recovery through user submissions and administrative verification.

*   **Technologies:** PHP, HTML, CSS, MySQL
*   **Key Features:**
    *   Users can report lost and found items.
    *   Admin can verify and manage submitted reports.
    *   Structured database management using MySQL.
    *   Supports the process of reconnecting reported items with their owners.
